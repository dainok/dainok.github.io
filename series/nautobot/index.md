[Nautobot](https://networktocode.com/nautobot/) is an open-source Network Source of Truth and Network Automation Platform. It centralizes the data of a network infrastructure and lets us automate repetitive tasks, manage the network more efficiently and reduce human error.

This series shows how to set up Nautobot, populate it with data from real devices and integrate it with tools like [Ansible](https://www.ansible.com/) to configure those devices. Each post includes practical examples that we can reproduce in a lab.
