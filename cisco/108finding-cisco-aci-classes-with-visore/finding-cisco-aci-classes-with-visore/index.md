Cisco ACI provides an object browser, **Visore**. We find it under `Tools` → `Object Store Browser`:

![[apic-tool-menu-2.png]]

Visore lets us search for objects by class, DN or URL and view their details and documentation. We can also download the JSON of a specific object and overwrite it:
