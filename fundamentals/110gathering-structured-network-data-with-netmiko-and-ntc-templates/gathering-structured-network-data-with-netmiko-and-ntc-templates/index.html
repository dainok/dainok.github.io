    Gathering structured network data with Netmiko and NTC Templates¶

    Andrea Dainese advanced cisco

    In the previous post we planned how to automatically collect information from a large number of devices. Let's now walk through how to address each requirement step by step, keeping in mind that, due to the tight timeline, the automation will be spaghetti code that is not easily reusable.

    Inventory¶

    Any automation requires a configuration file to store global parameters, and a place to store the credentials needed to access the devices. In our case, we chose to save the configuration in a config.yaml file.

    The inventory in particular is described by a list containing the FQDN and IP of each device:

    inventory:
  - fqdn: switch11.example.com
    ip: 172.25.80.11
  - fqdn: switch12.example.com
    ip: 172.25.80.12
  - fqdn: switch13.example.com
    ip: 172.25.80.13

    In our case, using only the FQDN was not sufficient because:

    • not all device FQDNs were resolvable via DNS
    • using only IP addresses to identify devices was not practical

    Data to collect¶

    Similarly to the previous point, we chose to use config.yaml to specify all the data to retrieve from the devices.

    commands:
  - show authentication sessions
  - show cdp neighbors detail
  - show dot1x all
  - show interfaces
  - show interfaces status
  - show interfaces switchport
  - show interfaces trunk
  - show inventory
  - show ip arp
  - show ip interface
  - show lldp neighbors detail
  - show logging last 200
  - show mac address-table dynamic
  - show running-config
  - show spanning-tree
  - show standby
  - show version
  - show vlan
  - show vrf

    All data needed for the assessment can be retrieved via show commands. Specifying the full list of commands to run on each device is therefore straightforward:

    • adding or removing a command is within anyone's reach
    • commands not supported by specific devices will simply produce empty or error output, which can then be ignored

    Device Access¶

    We established that the automation must access the devices via SSH, execute a command, collect the output, convert it to JSON, and save both the raw and JSON output to file.

    This is achieved as follows:

    • Netmiko handles device access and command execution
    • TextFSM with NTC Templates converts the output to JSON

    We use Netmiko to connect to a device:

    ip_address = device.get("ip")
hostname = device.get("fqdn").upper()
netmiko_cfg = {
    'device_type': "cisco_ios",
    'host': ip_address,
    'username': secrets.get("username"),
    'password': secrets.get("password"),
}
try:
    ssh = ConnectHandler(**netmiko_cfg)
except NetmikoTimeoutException:
    print(f"{hostname} ({ip_address}): CONNECTING (TIMEOUT)")
    return device, 'Timeout'

    Once connected, before running any commands, we set up the environment — specifically, we create the directory structure that will hold the output files and disable terminal paging on the connected device:

    device_dir = f"output/{timestamp}/{hostname}"
timestamp = datetime.now().strftime("%Y-%m-%d-%H:%M:%S")
os.makedirs("output", exist_ok=True)
os.makedirs(f"output/{timestamp}", exist_ok=True)
os.makedirs(device_dir, exist_ok=True)
ssh.send_command("terminal length 0")

    We then execute each command:

    for command in config.get("commands"):
    try:
        output = ssh.send_command(command, read_timeout=read_timeout)
    except ReadTimeout:
        print(f"{hostname} ({ip_address}): GETTING {command} (READTIMEOUT)")
        return device, 'ReadTimeout'

    We save the raw output to a dedicated TXT file:

    filename = f"{device_dir}/{slugify(command)}"
with open(f"{filename}.txt", "w") as fh:
    fh.write(output)

parsed_output = None

    We then convert the output to JSON and save it to a dedicated file, but only if the conversion was successful:

    parsed_output = None
try:
    parsed_output = get_structured_data(output, platform=platform, command=command)
except TextFSMError:
    pass
if isinstance(parsed_output, dict) or isinstance(parsed_output, list):
    with open(f"{filename}.json", "w", encoding="utf-8") as fh:
        json.dump(
            parsed_output,
            fh,
            indent=2,
        )

    Remember to disconnect from the device after the last command has been executed:

    ssh.disconnect()
