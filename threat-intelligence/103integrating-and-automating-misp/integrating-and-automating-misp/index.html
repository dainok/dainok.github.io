    Integrating and automating MISP¶

    Andrea Dainese beginner misp

    MISP is a platform for threat intelligence, not for incident management. Specifically, MISP helps manage Indicators of Compromise (IoCs) in a structured way, and therefore it must be integrated into an existing ecosystem.

    Very often, TheHive is used as the incident management platform, but integration requests also commonly involve Splunk, Elastic, Maltego, and detection and prevention systems (antispam, honeypot, firewall, etc.).

    A MISP event does not represent a security incident, but rather a threat that is analyzed and evaluated from a threat intelligence perspective. Much of the work (defining IoCs and artifacts) has likely already been carried out on other platforms: we are evaluating the event and its associated IoCs to determine whether they provide added value for us and for the communities we are part of.

    Automating MISP Tasks¶

    The following activities can be identified for automation:

    • Creating events by ingesting data from external sources (TheHive, honeypot, etc.)
    • Making IoCs available to external platforms (firewalls, EDR, antispam, SIEMs, etc.)
    • Facilitating incident analysis by providing IoCs to external platforms (Maltego, TheHive, etc.)
    • Sending and receiving feedback on events (thumbs up = observed and malicious, thumbs down = observed but not malicious)

    API¶

    MISP offers APIs in OpenAPI 3.0.0 format that allow programmatic interaction with the platform.

    To use the API, an authentication key is required. This key can be generated by navigating to My Profile → Auth keys → Add authentication key:

    The key must be included in the Authorization header.

    PyMISP¶

    Alternatively, the Python library PyMISP is available. PyMISP allows native interaction with MISP using Python.

    In my experience, I found PyMISP more challenging to use than the native APIs. This is primarily because the documentation is not always clear, and for some tasks, I had to reverse engineer the code.

    CIRCL¶

    CIRCL is the CERT for the private sector, municipalities, and non-governmental organizations in Luxembourg. CIRCL is a highly active contributor to MISP, and their website is worth visiting for its excellent MISP documentation.
