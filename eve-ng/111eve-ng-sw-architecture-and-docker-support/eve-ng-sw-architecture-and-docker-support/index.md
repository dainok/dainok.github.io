This presentation provides an in-depth overview of the EVE-NG software architecture, with a particular focus on its backend components, virtualization mechanisms, and the integration of Docker-based nodes.

It walks through the main architectural layers, from the AngularJS/PHP frontend and REST API framework to the internal handling of QEMU/KVM, networking models, and wrapper functions.

The final section highlights the software modifications implemented to extend EVE-NG with Docker support, including changes in PHP modules, wrappers, and system configuration. Together, these slides aim to give a clear understanding of how EVE-NG operates internally and how its capabilities can be expanded to support advanced virtual lab scenarios.
